# DietCam · 拍照记录饮食与运动

用手机拍一张照片、或打一行字 → 你自己的视觉大模型帮你分析 → 结果**归档成文件**，
需要时随时翻看。

**它不占用、也不污染任何聊天上下文。** 大多数「拍照问 AI」的方案会把每张照片都塞进对话里，
聊几天上下文就爆了。这个项目反过来：照片和分析结果只落盘，需要时主动去取。

## 它能做什么

| | |
| --- | --- |
| 📷 **拍照记一餐** | 快门后画面定格，可确认或重拍；原图另存一份到手机相册 |
| ⌨️ **打字记一餐** | 不想拍照就直接写「中午吃了一碗牛肉面」 |
| 🏃 **记录运动** | 描述一下（如「晚上慢跑了 5 公里」），自动估算时长、强度与消耗热量 |
| 🎯 **每日目标** | 填身高体重按 Mifflin-St Jeor 公式推算，也可以手动改 |
| 🍰 **放纵日** | 设个间隔（比如 7 天），主页显示倒计时，到那天提醒你放松一次 |
| 📅 **日历** | 有记录的日子带圆点，点开看当天吃了什么 |
| 🕘 **回忆** | 最近 7 / 30 / 90 天串成时间线 |
| 💬 **聊天里查** | 装了 AstrBot 的话，直接问「帮我看看这周碳水是不是偏高」 |

首页进度环显示**当日摄入 / 目标**；有运动时会多一行「运动消耗 X 千卡 · 净摄入 Y」。

## 两种用法

| | 连 AstrBot | 本地模式 |
| --- | --- | --- |
| 需要 AstrBot | 需要 | **不需要** |
| 照片和记录放在哪 | AstrBot 服务器（手机留一份缩略图缓存） | 全部在这台手机上 |
| 适合谁 | 自己用，想在聊天里 `/饮食` 查 | 给朋友用，或只想自己记账 |

安装后在「设置」最上方切换。**两种模式界面完全一样**，随时可换（但数据不互通）。

**本地模式**只要一个 OpenAI 兼容的视觉模型接口：

- 地址写到 `/v1` 就行，程序自动补 `/chat/completions`
- 模型名称点「拉取模型列表」直接从接口拉下来挑，不用手打
- 模型必须能看图：`qwen2.5-vl` / `gpt-4o` / `glm-4v` 这类

## 用 AstrBot 的话

1. 把 `astrbot_plugin_diet/` 整个目录放进 AstrBot 的 `data/plugins/`，重载插件
2. 在 WebUI 插件配置里填 `base_url`、`model`、`hmac_secret`（自己定一个随机串）
3. WebUI → 设置 → API Key，权限**勾选 `plugin`**，复制 `abk_...`
   > 这是 **AstrBot 自己的钥匙**，不是 OpenAI 的 key。模型的 key 填在插件配置里
4. App 里填「服务器地址 / AstrBot API Key / 签名密钥」

详细步骤见 [docs/部署指南.md](docs/部署指南.md)。

### 聊天指令

| 指令 | 结果 |
| --- | --- |
| `/饮食` | 今天的日报 |
| `/饮食 昨天` | 昨天（也认「前天」） |
| `/饮食 2026-06-27` | 指定日期（`6-27` 也认） |
| `/饮食 本周` · `/饮食 最近14天` · `/饮食 本月` | 区间汇总（含日均） |
| `/饮食 清理` · `/饮食 清理全部` | 清理没有记录引用的孤儿照片 |
| `/饮食状态` | 插件状态、数据目录、今日记录数 |

### 让模型自己查

插件注册了三个**只读**工具，你在聊天里直接问就行：

| 工具 | 能回答 |
| --- | --- |
| `diet_query_day` | 「我今天吃了多少」「昨天晚饭是什么」 |
| `diet_query_range` | 「这周蛋白质够吗」「本月日均热量」 |
| `diet_search` | 「上次吃鸡翅是什么时候」 |

> 只有模型真的调用了工具，那一小段查询结果才会进入对话上下文；
> 日常拍照记录依旧是纯文件落盘，不产生任何聊天消息。

## 我的数据在哪

**连 AstrBot 时**（默认在服务器的 `data/plugin_data/astrbot_plugin_diet/`）：

```
photos/2026-06-27/143210_a1b2c3d4.jpg   归档照片
records/2026-06-27.jsonl                当天记录（一行一条 JSON）
state.json                              目标、身体档案、放纵日设置
```

**本地模式时**：全在手机 App 私有目录 `diet/` 下，同样的结构。
**卸载即清空，注意自行备份。**

纯文字记录不产生照片，在 jsonl 里表现为 `photo` 为空、`source` 为 `app-text`、`note` 保留原始描述。

分析失败或中途中断的照片会被**立刻删掉**；删记录时也会顺带清理当天遗留的孤儿照片 ——
`records/` 和 `photos/` 基本保持一一对应，也可以用 `/饮食 清理全部` 手动收尾。

## 常见问题

**要花钱吗？** 项目本身免费。分析用的模型是你自己的 —— 本地跑不要钱，用云端的按你自己的账单。

**照片会传到哪？** 连 AstrBot 时传到**你自己的服务器**；本地模式时**根本不离开手机**。
两种情况下都不会经过任何第三方。

**换手机数据还在吗？** 连 AstrBot 在（数据在服务器）；本地模式不在。

**支持哪些手机？** Android 8.0（API 26）及以上。开发时主要在华为 Mate 50 Pro 上跑。

**更新怎么装？** App 会自己提示有新版本，点「下载更新」，下完点通知就能装。
也可以直接下最新 APK 覆盖安装 —— **不用卸载，数据保留**。

**能看华为运动的数据吗？** 暂时不能，见下面「还没做的」。

---

## 隐私

- 照片与记录只存在**你自己的服务器**或**你自己的手机**上。项目没有任何自己的后端服务。
- 本地模式下数据不离开设备；连 AstrBot 时数据只在你和设备之间传输，建议放在 HTTPS 反代之后。
- 上传接口除了 API Key，还要求一个 HMAC 签名的时效令牌，5 分钟过期。
